# Habit Tracker

A simple, practical habit-tracking app to help you build consistency and stay accountable every day.

## Overview

Habit Tracker helps you:
- Define habits you want to build
- Mark progress daily
- See your consistency over time
- Stay motivated with a clear view of your streaks

## Features

- ✅ Create and manage habits
- 📅 Track completion by day
- 📈 View progress and habit consistency
- 🔁 Build streaks and long-term momentum

## Why Habit Tracking Works

Habit tracking turns goals into visible actions. Instead of relying on motivation alone, you focus on showing up daily and maintaining consistency.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/SAKMOTO/Habit-tracker.git
cd Habit-tracker
```

Then run the project using the commands and setup used in this repository.

## Suggested Daily Workflow

1. Add or review your habits
2. Mark completed habits at the end of each day
3. Review weekly progress and adjust goals

## Project Goals

- Keep the tracker simple and easy to use
- Encourage consistency over perfection
- Make progress visible and motivating
